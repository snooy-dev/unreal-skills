# unreal-skills

`unreal-skills` provides the `$unreal-coding` skill for implementing and validating Unreal Engine C++ changes. It selects Live Coding, Hot Reload, or a closed-editor UnrealBuildTool build from the current editor and build state.

## Installation

Install `unreal-skills` from the Codex plugin directory, then start a new task. For local development, clone this repository and use `$plugin-creator` to add the plugin folder to a local marketplace before installing it.

## Commands

- `$unreal-coding <task>` — Implement and validate an Unreal Engine C++ change with the appropriate build workflow.
